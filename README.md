### Production Systems

#### AeroFlazz — Digital Distribution &amp; PPOB Gateway
- **Core:** High-throughput transactional backend in **Go (Fiber v2)** &amp; **PostgreSQL** operating under strict ACID boundaries.
- **Accounting:** Enterprise **Double-Entry General Ledger Engine** enforcing mathematical Zero-Sum Invariant (`Total Debit == Total Credit`), preventing untracked balance drift.
- **Security:** Pessimistic row locking (`SELECT FOR UPDATE`), Redis distributed mutex, bank-grade HttpOnly session cookie protection, and automated emergency circuit breaker containment.
- **Stack:** `Go` • `Fiber` • `PostgreSQL` • `Redis` • `Next.js 16` • `TypeScript` • `Nginx`
- **Deploy:** [Live Platform (aeroflazz.com)](https://aeroflazz.com) • [Founder Profile](https://aeroflazz.com/tentang-kami)

---

#### PaySaku v2 — Real-Time Payment Gateway &amp; Mutation Engine
- **Core:** Native **Rust (Tokio / Axum)** asynchronous gateway with sub-millisecond webhook routing and zero-overhead memory footprint.
- **Cryptography:** Asymmetric **Ed25519 digital signatures** (Open Banking SNAP BI &amp; FAPI Non-Repudiation) with Zero Private Key Storage and strict canonical payload validation.
- **Reliability:** Dual-engine automated mutation reconciliation (GoBiz &amp; ShopeePay), cryptographic HMAC-SHA256 signature enforcement, and SSRF-hardened webhook dispatcher.
- **Stack:** `Rust` • `Tokio` • `Axum` • `React 19` • `TypeScript` • `PostgreSQL` • `Ed25519`
- **Deploy:** [Live Platform (paysaku.site)](https://paysaku.site) • [API Documentation](https://paysaku.site/docs)

---

#### Kertanusa — Precision Agriculture &amp; Telemetry Platform
- **Core:** Full-stack decision support system calculating soil water balance (**FAO-56**) via global telemetry (**ECMWF, NOAA, BMKG**).
- **Inference:** Multimodal computer vision plant pathology diagnosis with sub-2s inference latency.
- **Stack:** `Next.js 15` • `TypeScript` • `Tailwind CSS` • `Multimodal Vision AI` • `Leaflet GIS`
- **Deploy:** [Source Repository](https://github.com/riiardian/kertanusa)
